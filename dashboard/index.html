How the gate works
  1. A tool acts, then independently re-reads the result from the counterparty's own system. The booking API saying confirmed is a claim; a row appearing on re-read is evidence.
  2. Only the tool layer writes evidence to the ledger. The model never does.
  3. claim_task_complete accepts a token only if the tool layer recorded it. Otherwise it raises FabricationBlocked and the agent's only remaining move is an honest partial report.
