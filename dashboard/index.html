The verification gate

Every success claim, and whether it survived.

The agent has no free-form way to say “done.” It must call claim_task_complete with a token, and the gate accepts that token only if the tool layer recorded it first. Six refusals below are not bugs. They are the product working.

A tool acts, then independently re-reads the result from the counterparty’s own system.

The booking API saying confirmed is a claim. A row appearing on re-read is evidence. Only the tool layer writes evidence to the ledger — the model never does.
